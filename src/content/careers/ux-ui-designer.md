## Job Description

Sikaverts is looking for a creative UI/UX Designer to design modern, intuitive, and user-friendly experiences for websites, web applications, and digital products. You will work closely with developers and project teams to transform ideas and requirements into engaging digital experiences.

## Job Responsibilities

**\*\*Design user interfaces —\*\*** Create clean, modern, responsive interfaces for websites, web applications, and digital products.

**\*\*Create wireframes and prototypes —\*\*** Develop wireframes, user flows, mockups, and interactive prototypes to communicate design concepts.

**\*\*Develop design systems —\*\*** Create reusable UI components, design guidelines, typography systems, and visual styles for consistent digital experiences.

**\*\*Understand user requirements —\*\*** Analyze project requirements and user needs to create intuitive and practical design solutions.

**\*\*Collaborate with developers —\*\*** Work closely with frontend and backend developers to ensure designs are implemented accurately and effectively.

**\*\*Improve user experience —\*\*** Identify usability issues and continuously improve navigation, accessibility, responsiveness, and overall user experience.

## Qualifications

**\*\*UI/UX fundamentals —\*\*** Good understanding of user experience, interface design, layout, typography, color, spacing, and responsive design.

**\*\*Design tools —\*\*** Experience with Figma or similar UI/UX design tools.

**\*\*Creative thinking —\*\*** Ability to create visually appealing designs while keeping usability and functionality in mind.

**\*\*Responsive design knowledge —\*\*** Understanding of how interfaces should adapt across desktop, tablet, and mobile devices.

**\*\*Communication skills —\*\*** Ability to explain design decisions and collaborate effectively with developers and project teams.

## Bonus Points

- Experience designing websites and web applications
- Basic knowledge of HTML and CSS
- Familiarity with responsive web design
- Experience creating design systems and reusable components
- Knowledge of accessibility and usability principles
- Familiarity with Adobe XD, Photoshop, Illustrator, or similar tools
- Experience with animation and micro-interactions
- Understanding of frontend technologies such as React.js
- Experience designing AI/ML or technology-based applications

## What We Offer

- Opportunity to work on real-world websites and digital products
- Experience designing modern web applications
- Collaboration with developers and technology teams
- Opportunity to build a strong professional design portfolio
- Exposure to web development, software, AI, and emerging technologies
- Creative and learning-focused project environment
- Opportunities to work on innovative digital solutions
