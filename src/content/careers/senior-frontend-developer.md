## Job Description

Sikaverts is looking for a passionate Full-Stack Developer to build modern websites, web applications, and custom digital solutions. You will work across frontend, backend, databases, and APIs to transform project requirements into reliable and user-friendly applications.

## Job Responsibilities

**\*\*Develop modern web applications —\*\*** Build responsive, scalable, and user-friendly web applications using modern frontend and backend technologies.

**\*\*Build frontend interfaces —\*\*** Create clean and responsive user interfaces using HTML, CSS, JavaScript, React.js, or other suitable technologies.

**\*\*Develop backend systems —\*\*** Build server-side functionality, APIs, authentication systems, and business logic for web applications.

**\*\*Work with databases —\*\*** Design, manage, and integrate databases such as MySQL, MongoDB, or other suitable database systems.

**\*\*Integrate APIs —\*\*** Develop and consume REST APIs and integrate third-party services when required.

**\*\*Optimize applications —\*\*** Improve application performance, security, responsiveness, and overall user experience.

**\*\*Collaborate on projects —\*\*** Work with the team to understand requirements, solve technical challenges, and deliver complete digital solutions.

## Qualifications

**\*\*Strong web development fundamentals —\*\*** Good understanding of HTML, CSS, JavaScript, responsive design, and modern web development practices.

**\*\*Frontend development —\*\*** Experience with React.js, Astro, Vue.js, or another modern frontend framework is an advantage.

**\*\*Backend development —\*\*** Knowledge of Node.js, Python, PHP, or another backend technology.

**\*\*Database knowledge —\*\*** Understanding of MySQL, MongoDB, PostgreSQL, or other database systems.

**\*\*Problem-solving skills —\*\*** Ability to analyze requirements, debug applications, and develop practical solutions.

## Bonus Points

- Experience with React.js, Astro, Next.js, or Vite
- Knowledge of Node.js, PHP, Python, Flask, or Django
- Experience with MySQL or MongoDB
- Familiarity with Git and GitHub
- Experience developing REST APIs
- Knowledge of cloud deployment and website hosting
- Interest in AI, machine learning, or automation
- Understanding of UI/UX and responsive web design

## What We Offer

- Opportunity to work on real-world web and software projects
- Exposure to modern development technologies
- Experience with frontend, backend, databases, and APIs
- Opportunity to work on AI/ML and automation projects
- Collaborative and learning-focused environment
- Opportunities to develop your technical and professional skills
- Flexible working opportunities depending on the project and role
