## Job Description

Sikaverts is looking for a passionate AI/ML Developer to design and develop intelligent applications that solve real-world problems. You will work with machine learning, deep learning, computer vision, and data-driven technologies to transform ideas into practical AI-powered solutions.

## Job Responsibilities

**\*\*Develop AI/ML solutions —\*\*** Design, train, evaluate, and deploy machine learning models for real-world applications.

**\*\*Build intelligent applications —\*\*** Integrate AI and machine learning models into websites, software applications, and digital products.

**\*\*Work with data —\*\*** Collect, clean, preprocess, analyze, and visualize datasets required for machine learning projects.

**\*\*Develop computer vision solutions —\*\*** Work on image classification, object detection, image processing, and other computer vision applications when required.

**\*\*Train and optimize models —\*\*** Experiment with different algorithms, architectures, hyperparameters, and evaluation techniques to improve model performance.

**\*\*Integrate AI with applications —\*\*** Connect trained models with web applications, APIs, databases, and other software systems.

**\*\*Research new technologies —\*\*** Explore emerging AI/ML techniques and identify opportunities to apply them to real-world projects.

## Qualifications

**\*\*Programming skills —\*\*** Good knowledge of Python and familiarity with libraries such as NumPy, pandas, and scikit-learn.

**\*\*Machine learning fundamentals —\*\*** Understanding of supervised learning, unsupervised learning, model evaluation, and basic deep learning concepts.

**\*\*Deep learning knowledge —\*\*** Familiarity with TensorFlow, Keras, PyTorch, or similar frameworks.

**\*\*Data handling —\*\*** Ability to preprocess datasets, perform exploratory data analysis, and visualize results.

**\*\*Problem-solving skills —\*\*** Ability to understand real-world problems and develop practical technology-based solutions.

## Bonus Points

- Experience with CNNs, Vision Transformers, or other deep learning architectures
- Knowledge of computer vision and image processing
- Experience with OpenCV, TensorFlow, Keras, or PyTorch
- Familiarity with Flask, Django, FastAPI, or REST APIs
- Experience integrating ML models into web applications
- Knowledge of NLP or generative AI
- Familiarity with Git and GitHub
- Experience working with cloud platforms or model deployment
- Research or academic project experience in AI/ML

## What We Offer

- Opportunity to work on real-world AI and machine learning projects
- Experience with modern AI and deep learning technologies
- Opportunity to develop computer vision and intelligent applications
- Exposure to web, software, and AI integration projects
- Collaborative and learning-focused environment
- Opportunities to build a strong AI/ML portfolio
- Opportunities to explore innovative solutions to real-world problems

## How to Apply

If you are passionate about artificial intelligence, machine learning, and building technology that solves real-world problems, we'd love to hear from you.

**Send your resume, GitHub profile, portfolio, and details of relevant AI/ML projects to the Sikaverts team to apply for this opportunity.**
