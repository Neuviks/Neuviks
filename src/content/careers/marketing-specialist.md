## Job Description

Sikaverts is looking for a motivated Web Developer Intern who is interested in building modern websites and web applications. You will work on real-world projects and gain practical experience in frontend development, backend integration, databases, and responsive web design.

## Job Responsibilities

**\*\*Develop modern websites —\*\*** Build responsive and user-friendly websites using HTML, CSS, JavaScript, and modern web technologies.

**\*\*Build web applications —\*\*** Develop functional web applications based on project requirements and client needs.

**\*\*Work with databases —\*\*** Integrate websites and applications with databases such as MySQL and work with backend technologies.

**\*\*Optimize user experience —\*\*** Improve website performance, responsiveness, accessibility, and overall user experience.

**\*\*Collaborate on projects —\*\*** Work with the development team to understand requirements, solve technical problems, and deliver project features.

## Qualifications

**\*\*Basic web development knowledge —\*\*** Understanding of HTML, CSS, and JavaScript.

**\*\*Programming knowledge —\*\*** Basic knowledge of JavaScript, Python, PHP, or another programming language.

**\*\*Problem-solving skills —\*\*** Ability to understand problems, research solutions, and implement them effectively.

**\*\*Willingness to learn —\*\*** Strong interest in learning new technologies and working on real-world projects.

## Bonus Points

- Experience with React.js or other frontend frameworks
- Knowledge of PHP and MySQL
- Familiarity with Git and GitHub
- Basic knowledge of UI/UX design
- Interest in AI, machine learning, or automation
- Previous academic or personal web development projects

## What You Can Gain

- Practical experience working on real-world projects
- Exposure to modern web development technologies
- Experience with frontend, backend, and database development
- Opportunity to work on client-focused digital solutions
- Guidance and technical learning opportunities
- Project experience that can strengthen your portfolio

## How to Apply

If you are passionate about technology and interested in building real-world digital solutions, we'd love to hear from you.

**Send your resume and portfolio to the Sikaverts team to apply for this opportunity.**
